        ┌──────────────────────────────────────────┐

              ┌────────────┴────────────┐
              ▼                         ▼
        ┌──────────┐            ┌──────────────┐

              │                         │

              ┌─────────────────────────────┐
              │   REPARAMETERIZATION        │

              └─────────────────────────────┘
                           │
                           ▼
        ┌──────────────────────────────────────────┐
        │           DECODER NETWORK                │
        │  ┌────────────────────────────────────┐  │

        │  │  BatchNorm + LeakyReLU + Dropout   │  │
        │  └────────────────────────────────────┘  │
        │  ┌────────────────────────────────────┐  │
        │  │  Linear(64 → 128)                  │  │
        │  │  BatchNorm + LeakyReLU + Dropout   │  │
        │  └────────────────────────────────────┘  │
        │  ┌────────────────────────────────────┐  │
        │  │  Linear(128 → 256)                 │  │
        │  │  BatchNorm + LeakyReLU + Dropout   │  │
        │  └────────────────────────────────────┘  │
        │  ┌────────────────────────────────────┐  │
        │  │  Linear(256 → N)                   │  │
        │  └────────────────────────────────────┘  │
        └──────────────────────────────────────────┘
                           │

                 Reconstructed Output
                     (N features)

    Loss = Reconstruction Loss + β * KL Divergence
         = MSE(x, x̂) + β * KL(q(z|x) || p(z))
